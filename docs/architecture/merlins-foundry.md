# Merlin’s Foundry Architecture  

## Controlled Software Production Cartridge for Camelot-OS

Merlin’s Foundry is Camelot-OS’s **software production cartridge**: it converts an approved Blueprint OS task into a bounded engineering workcell, selects the correct coding runtime, produces a candidate patch, collects deterministic evidence, and returns the result to Gideon for independent verification.

## Purpose

Blueprint OS defines the approved job. Merlin’s Foundry decomposes and routes engineering work. Sentinel grants exact permissions. VFS Guardian creates the sandbox. Boris and Socrates test and constrain. Gideon decides whether evidence is sufficient. Promotion remains human-gated where consequential.

## Foundry operating law

Merlin selects and coordinates. HiVeiDe maps and locks. Sentinel leases. VFS contains. Runtimes propose patches. Boris tests. Socrates constrains. Gideon decides. Humans promote. Receipts prove.
