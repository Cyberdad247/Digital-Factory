# Titan Omni Forge Architecture
## Integrated Composite Engineering Factory

**Titan Omni Forge** is the integrated product mode and composite cartridge of Camelot-OS, unifying the Merlin Software Agency, Blueprint OS, Hive IDE, and Merlin Engineering Foundry into a cohesive no-code-to-verified-code factory.

## Composition
Titan Omni Forge is a composite integration of four distinct engineering engines:
1. **Merlin Software Agency**: Architecture + Scientific Assurance.
2. **Blueprint OS**: Architecture-to-Implementation Planning (Kinetic).
3. **Hive IDE / HiVeiDe**: Agentic Repository Intelligence + Coding Factory.
4. **Merlin Engineering Foundry**: Pill Execution + Evidence Collection + Workcell Governance.

## Governance & Boundary
Titan Omni Forge operates within the strict governance of Camelot Core (Sentinel, VFS Guardian, Gideon, Receipt Service). It does not issue leases, alter policies, or promote code itself; it manufactures and verifies implementation candidates that are ultimately promoted via human-gated or policy-validated governance workflows.
