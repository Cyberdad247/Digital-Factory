1. **Analyze Codebase & Map Backend APIs**: Parse schema, RPC methods, and memory footprints.
2. **Design Subcommand Architecture**: Build hierarchical command tree with typed flags and deterministic exit codes.
3. **Scaffold JSON-Structured Outputs**: Standardize on Token-Oriented Object Notation (TOON) over Stdio JSON-RPC 2.0.
4. **Implement REPL & Execution Handlers**: Generate production-ready Node/TS executable with robust error handling.
5. **Generate TEST.md**: Audit AST diffs and execute isolated VFS assertion suite.
6. **Compile HARNESS.md**: Author technical operational manual for autonomous agents.
7. **Generate SKILL.md**: Publish canonical block ID for instant swarm discovery.
